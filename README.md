# Taked POS — Releases
> توزيع إصدارات تطبيق "تأكيد" (Taked POS) لسطح المكتب.

## المحتويات
- `windows/` — نسخ Windows portable (مضغوطة)
- `apk/` (لاحقاً) — نسخ APK مباشرة للأندرويد

## التحميل
اذهب إلى قسم [Releases](../../releases) واختر آخر إصدار.

## التنصيب (Windows)
1. حمّل ملف `.zip` من آخر Release.
2. فك الضغط في مجلد مخصص (مثال: `C:\Taked`).
3. شغّل `Taked.exe`.

## التنصيب (Android)
يُنصح بالتحميل من Google Play:
[صفحة التطبيق](https://play.google.com/store/apps/details?id=com.taked.salesapp.cloud)
